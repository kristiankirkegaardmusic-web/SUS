# SUS — Sonic Umwelt Stimulation

Static GitHub Pages site.

## Deploy
1. Upload **all files and the `assets` folder** to the root of the GitHub repository.
2. In GitHub: Settings → Pages → Deploy from a branch → `main` / root.
3. Wait for the Pages build to finish.

## Important: video
The main 06:33 demo is encoded as `assets/sus-demo.mp4` in H.264/AAC with web fast-start and is ~19 MB, so it can be uploaded through GitHub's browser interface. Do not replace it with the original ~400 MB MOV file.

The site uses only relative paths and has no build step or external framework dependencies.
