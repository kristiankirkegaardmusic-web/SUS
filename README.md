# SUS — Sonic Umwelt Stimulation

Statisk B2B-site klar til GitHub Pages.

## Udgiv på GitHub Pages
1. Opret et nyt GitHub repository.
2. Upload **indholdet** af denne mappe til repositoryets root (index.html skal ligge øverst).
3. Gå til **Settings → Pages**.
4. Under **Build and deployment**, vælg **Deploy from a branch**.
5. Vælg `main` og `/ (root)`, og tryk Save.

Siden bruger ingen build tools, frameworks eller eksterne CDN'er.

## Vigtige filer
- `index.html` — hele siden
- `styles.css` — design og responsivitet
- `script.js` — menu, header og scroll-reveals
- `assets/sus-demo.mp4` — weboptimeret hoveddemo
- `assets/SUS-bachelorprojekt.pdf` — bachelorprojektet

## Kontaktlinks
Kontaktoplysninger, LinkedIn og portfolio kan ændres direkte i `index.html`.
