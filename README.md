# SUS — En lydoplevelse, man går igennem.

## Åbn hjemmesiden

Pak ZIP-filen ud, og åbn index.html. Behold assets-mappen sammen med index.html,
styles.css og script.js.

## GitHub Pages

1. Pak ZIP-filen ud. Upload indholdet til dit repository — ikke selve ZIP-filen.
2. index.html skal ligge direkte i roden sammen med styles.css, script.js og assets-mappen.
3. Upload hele assets-mappen: den indeholder begge videoer, billeder og bacheloropgaven.
4. Under Settings → Pages vælges Deploy from a branch, main og / (root). Gem.
5. Åbn adressen, der vises under Pages, når GitHub er færdig.

Siden kræver ingen installation, API-nøgler eller buildproces. Alle mediestier er relative.

## Den opdaterede hjemmeside

- Overskrift: En lydoplevelse, man går igennem.
- Ren forside uden tekst oven på billeder. Intet kontaktafsnit.
- To videoer med tydelig forklaring om, at lyden er proof of concept.
- Testresultater med fire deltagere angivet og henvisninger til bacheloropgaven.
- Platform, metode og beacon-funktionen beskrevet.

## Redigering

Tekster: index.html
Design og mobilvisning: styles.css
Videoafspilning: script.js
Videoer, billeder og opgave: assets/

ZIP-filen opdaterer ikke automatisk en allerede udgivet hjemmeside.
