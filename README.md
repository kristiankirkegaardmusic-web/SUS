# SUS — GitHub Pages

## Upload hjemmesiden

1. Pak ZIP-filen ud.
2. Upload index.html, styles.css og hele assets-mappen til dit GitHub-repository.
   index.html skal ligge direkte i roden, ikke inde i en ekstra mappe.
3. Hvis du opdaterer den gamle hjemmeside, erstat HTML og CSS og fjern de gamle
   videofiler og PDF-filer fra assets. script.js bruges heller ikke længere.
4. Under Settings → Pages: vælg Deploy from a branch, main og / (root), og gem.
5. Åbn adressen under Pages, når GitHub er færdig.

Hele denne version er lille nok til almindelig upload gennem GitHubs browser.
Ingen installation, buildproces, videofiler eller API-nøgler er nødvendige.

## Videoerne

Videoerne afspilles via YouTube direkte på hjemmesiden:

- Hoveddemo: https://www.youtube.com/watch?v=EmNkbqmhPho
- Fortællingsdemo: https://www.youtube.com/watch?v=-wYvmmW34XY

Begge videoer har fortsat en tydelig forklaring om, at lyden er proof of concept.
Afspillerne tilpasser sig mobil og computer og har fuldskærmsvisning.
Der er også et direkte YouTube-link under hver video.

Videoerne kræver internet. Afprøv afspilningen på GitHub Pages; når index.html
åbnes direkte som en lokal fil, kan YouTube afvise afspilning uden en webadresse.
Hvis YouTube oplyser, at indlejring ikke er tilladt, skal tilladelsen aktiveres
for den pågældende video i YouTube Studio.

## Redigering

Tekster og YouTube-links: index.html
Design og mobilvisning: styles.css
Billeder: assets/

Resultater og metode står direkte på hjemmesiden. Ingen opgave er vedlagt eller
linket fra hjemmesiden. Kontaktafsnittet er fortsat fjernet.
